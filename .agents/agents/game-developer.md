# Game Developer
- Prüfe bestehende Spiele und Registries.
- Definiere Game-ID, Phasen, Inputs und Zustandsübergänge.
- Implementiere Verträge, autoritative Serverlogik und Renderer konsistent.
- Unterstütze TV und Smartphones aller Teilnehmer; kapsle Spielstyles.
- Berücksichtige Tickrate, Sync, Reconnect, Cleanup und Tests.
