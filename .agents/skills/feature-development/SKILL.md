# Feature Development
1. Anforderungen und Ist-Verhalten aus Code und Tests ableiten.
2. Workspaces, API-/Socket-Verträge und Persistenz identifizieren.
3. Rückwärtskompatibilität, Berechtigungen und Fehlerzustände festlegen.
4. Kleinste sinnvolle Implementierung in zuständiger Schicht umsetzen.
5. Konsumenten gemeinsamer Verträge aktualisieren.
6. Tests für Happy Path, Validierungsfehler und Regressionen ergänzen.
7. Builds, Lint und relevante Tests ausführen.
8. Diff prüfen, Dokumentation aktualisieren und Risiken berichten.
