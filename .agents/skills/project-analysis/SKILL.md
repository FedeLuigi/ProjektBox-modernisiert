# Project Analysis
1. AGENTS.md und relevante Rules lesen.
2. Betroffene Dateien, Aufrufer, Typen, Tests, Scripts und Git-Diff untersuchen.
3. Workspaces zuordnen: shared, ui, tv, smartphone, server.
4. Bei Multiplayer Datenfluss von Eingabe über Socket/Server bis Persistenz/Anzeige nachvollziehen.
5. Sicherheits-, Kompatibilitäts-, Performance-, Accessibility- und Migrationsrisiken prüfen.
6. Ziel, Nicht-Ziele, Schichten, Schritte und Verifikation bestimmen.
7. Kleine Aufgaben direkt erledigen; größere anhand einer Checkliste umsetzen.
8. Diff und Checks prüfen; Annahmen/offene Punkte berichten.
